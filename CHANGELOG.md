# История изменений

## 1.0.2 — 2026-09-09

Усиление веб-авторизации без изменения схемы базы и SMS-функций.

### Авторизация

- ошибки логина/пароля, TOTP и quick-login отображаются одинаково: `Неверные данные входа`;
- `password_verify()` выполняется независимо от совпадения имени пользователя;
- при временной IP-блокировке сервер возвращает HTTP 429 и `Retry-After`;
- заблокированному IP форма авторизации не выдаётся;
- добавлен глобальный limiter неверных TOTP после успешной проверки логина и пароля;
- по умолчанию 10 неверных TOTP за 10 минут блокируют дальнейшую проверку TOTP на 15 минут;
- существующая IP-защита и совместимость с Fail2Ban сохранены;
- ошибки quick-login и попытки во время глобальной TOTP-блокировки учитываются тем же IP-limiter;
- активная IP-блокировка сохраняется при параллельных запросах, уже прошедших предварительную проверку.

### Быстрый вход

- срок действия quick-login по умолчанию сокращён с 24 часов до 30 минут;
- пароль по-прежнему обязателен;
- quick-login заменяет только TOTP;
- уведомления о событиях авторизации больше не создают quick-login token;
- уведомления о новых SMS сохраняют quick-login там, где он разрешён для канала;
- использованный token нельзя применить повторно.

### Интерфейс

- сообщение об ошибке авторизации выровнено по центру.

### SQLite

- схема базы не изменялась;
- `PRAGMA user_version` остаётся равным `6`;
- миграция 1.0.1 → 1.0.2 не требуется;
- глобальный TOTP limiter использует существующую таблицу `app_state`.

## 1.0.1 — 2026-09-07

Обновление веб-авторизации и уведомлений.

### Быстрый вход

- добавлены одноразовые ссылки быстрого входа из уведомлений;
- быстрый вход можно независимо разрешить для Telegram, MAX и Matrix;
- при переходе по такой ссылке логин и пароль остаются обязательными;
- действующая одноразовая ссылка заменяет только ввод TOTP;
- для каждого уведомления и канала создаётся новый случайный ключ;
- срок действия ссылки по умолчанию составляет 24 часа;
- допустимый срок действия ссылки — от 5 минут до 7 дней;
- добавлена CLI-утилита `bin/quick-login-token.php` для ручного создания одноразовой ссылки администратором;
- после успешного входа ключ сразу удаляется из базы;
- неиспользованные просроченные ключи удаляются периодическим `cron/poll.php`;
- в SQLite хранится только SHA-256 ключа, без его исходного значения;
- одноразовая часть ссылки передаётся через фрагмент `#access`, поэтому не попадает в обычный URL запроса к nginx или обратному прокси.

### Уведомления

- ссылка быстрого входа отображается в сообщении как обычный адрес веб-интерфейса;
- для Telegram и MAX отключается предпросмотр страницы;
- Telegram и MAX поддерживают скрытую фактическую ссылку быстрого входа;
- обычные ссылки сохраняются для каналов, где быстрый вход не разрешён.

### SQLite

- текущая схема базы изменена с `PRAGMA user_version = 5` на `PRAGMA user_version = 6`;
- обновление существующей базы 1.0.0 выполняет один переход `5 → 6`;
- новая установка 1.0.1 сразу создаёт schema 6;
- добавлена таблица `auth_quick_login_tokens` для действующих одноразовых ссылок.

Интерфейс пользовательских SMS-команд и формат подключения Bash- и Python-плагинов не изменялись.

## 1.0.0 — 2026-09-04

Первый публичный выпуск Huawei SMS.

### Возможности

- перенос входящих и исходящих SMS из памяти Huawei в SQLite с последующей очисткой памяти модема;
- веб-интерфейс для просмотра, удаления и отправки SMS;
- выполнение SMS-команд только с доверенных телефонных номеров;
- подключение собственных Bash- и Python-обработчиков через `commands.local.php` и `scripts.local/`;
- штатные команды `Пинг`, `Порт` и `Модем`;
- проверка аргументов, ограничение времени выполнения и объёма ответа пользовательских обработчиков;
- журнал выполнения команд и безопасное продолжение отправки многочастного ответа без повторного запуска обработчика;
- контроль доступности модема с уведомлениями об отказе и восстановлении;
- плановая перезагрузка Huawei через HiLink API;
- уведомления через Telegram, MAX и Matrix;
- прокси с авторизацией и необязательным прямым резервным подключением для Telegram и MAX;
- парольная авторизация, защита от перебора, CSRF и необязательный второй фактор TOTP;
- автоматическое создание и обновление рабочей базы SQLite до `PRAGMA user_version = 5`;
- подробное руководство по созданию и подключению собственных SMS-команд.
