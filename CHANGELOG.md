# История изменений

## 1.0.0 — 2026-09-04

Первый публичный выпуск Huawei SMS.

### Возможности

- перенос входящих и исходящих SMS из памяти Huawei в SQLite с последующей очисткой памяти модема;
- веб-интерфейс для просмотра, удаления и отправки SMS;
- выполнение SMS-команд только с доверенных телефонных номеров;
- подключение собственных Bash- и Python-обработчиков через `commands.local.php` и `scripts.local/`;
- штатные команды `Пинг`, `Порт` и `Модем`;
- проверка аргументов, ограничение времени выполнения и объёма ответа пользовательских обработчиков;
- журнал выполнения команд и безопасное продолжение отправки многочастного ответа без повторного запуска обработчика;
- контроль доступности модема с уведомлениями об отказе и восстановлении;
- плановая перезагрузка Huawei через HiLink API;
- уведомления через Telegram, MAX и Matrix;
- прокси с авторизацией и необязательным прямым резервным подключением для Telegram и MAX;
- парольная авторизация, защита от перебора, CSRF и необязательный второй фактор TOTP;
- автоматическое создание и обновление рабочей базы SQLite до `PRAGMA user_version = 5`;
- подробное руководство по созданию и подключению собственных SMS-команд.
