# Сторонние компоненты

Huawei SMS не содержит внутри репозитория сторонних PHP-фреймворков, JavaScript-библиотек, Python-пакетов или бинарных файлов.

Проект использует программы и библиотеки, которые устанавливаются средствами операционной системы и сохраняют собственные лицензии.

## Серверная часть

### PHP

Huawei SMS написан на PHP и использует стандартные возможности PHP и расширения:

- cURL;
- mbstring;
- PDO;
- PDO SQLite;
- SimpleXML;
- sessions;
- OpenSSL/хеширование, доступное в стандартной сборке PHP.

PHP распространяется на условиях лицензии PHP.

### SQLite

SQLite используется как локальная база данных через PDO SQLite.

SQLite находится в общественном достоянии согласно условиям самого проекта SQLite.

### Python 3

Python 3 нужен для:

```text
bin/command-runner.py
scripts/network-check.py
```

Внешние пакеты PyPI не требуются.

Python распространяется по условиям Python Software Foundation License.

### Bash

Bash используется штатным обработчиком:

```text
scripts/modem-health.sh
```

и может использоваться пользовательскими плагинами.

Bash распространяется на условиях GNU GPL.

### curl

Командная утилита `curl` нужна штатной диагностике модема. PHP-расширение cURL используется для Huawei API и каналов уведомлений.

### iputils ping

Утилита `ping` используется штатной командой `Пинг` и диагностикой модема.

### util-linux flock

`flock` используется Bash-диагностикой Huawei для согласования доступа к API модема, если путь блокировки передан через окружение.

## Веб-сервер и служба запуска

Примеры конфигурации рассчитаны на:

- nginx;
- PHP-FPM;
- systemd или cron.

Эти программы не входят в Huawei SMS и устанавливаются отдельно.

## Telegram, MAX и Matrix

Поддержка этих сервисов реализована обычными HTTP-запросами. Официальные SDK в проект не включены.

Huawei SMS не является частью Telegram, MAX, Matrix.org или Huawei и не распространяет их программное обеспечение.

## Пользовательские плагины

Скрипты, которые администратор самостоятельно помещает в `scripts.local/`, не являются частью стандартного Huawei SMS. Их зависимости и лицензии определяет автор конкретного плагина.
